## Read the Full Seats Count

Open **User Management** to see your users and the **Full Seats** count. The first number shows seats currently used or reserved; the second shows your seat limit.

| User or invitation | Full Seats used |
| --- | --- |
| Regular user | 1 |
| Admin | 0 |
| Pending invitation for a regular user | 1 reserved seat |

For example, with **2 admins**, **1 regular user**, no pending invitations, and a limit of **5 seats**, the count shows **1/5 Full Seats**. Admins still appear in the user list.

## Change a User's Role

After you save a role change, the Full Seats count refreshes automatically:

- Changing a regular user to **Admin** frees one full seat.
- Changing an **Admin** to a regular user uses one full seat.

<Note>
  Pending regular-user invitations reserve seats before the invitees join, so the Full Seats count can be higher than the number of regular users already in your team.
</Note>
