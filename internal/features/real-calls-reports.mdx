## Overview

Real Calls Reports provide manager/admin reporting over real call performance inside the unified team Reports workspace. The feature combines call filters, evaluation data, users, groups, workspaces, and scorecards to support performance analysis.

The page title is **Reports**. Real calls and simulations are two top-level tabs, **Real calls | Simulations**, above the filters. The canonical explicit route is `/admin/team/reports?type=real-calls`. The legacy `/admin/team/real-calls-reports` route redirects to the unified Reports page with the Real calls tab selected.

Which tab opens:

1. A valid `type` query parameter (`real-calls` or `simulations`) wins.
2. Otherwise, the last tab the manager picked, stored in localStorage key `reports-report-type`.
3. Otherwise, the tenant default: Real calls when the tenant has the `REAL_CALLS` feature (always in local development), else Simulations.

When the tenant does not have real calls, the tabs are hidden, the page shows Simulations only, and any request for real calls (URL or stored value) falls back to simulations.

## Call Detail Drilldown

Rows that open Call Analysis use the real-call header behavior documented in `internal/features/call-analysis.mdx`.

Managers and team leads can correct language, call type, and outcome from the call detail header. Admins can also edit the call title and reassign the call owner. Regular users see those metadata values as read-only.

Successful metadata and assignment saves do not show confirmation toasts; failed saves show destructive error toasts and restore optimistic metadata selections where applicable.

Source references:

- `src/app/(auth)/call-analysis/[callId]/page.tsx`
- `src/components/analysis/header/useCallAnalysisHeaderActions.ts`

## Unified Reports Workspace

| UI area | Frontend source | Behavior |
| --- | --- | --- |
| Report type tabs | `src/components/teamManagement/reports/ReportTypeTabs.tsx`, rendered by `ReportsWorkspace.tsx` | Top-level **Real calls / Simulations** tabs shown above the filters. Replaces the former report-type dropdown in the filter row (`reportTypeSelect.tsx`, removed). Only rendered when the tenant can view real calls. |
| Report type routing | `src/components/teamManagement/reports/useReportTypeRouting.ts` | Resolves the active tab: valid `type` URL param, then localStorage key `reports-report-type`, then the tenant default (real calls if available, else simulations). Stored values other than `real-calls` normalize to simulations. Picking a tab stores the choice and sets `type=real-calls` or `type=simulations` in the URL. The workspace renders nothing until the tenant has loaded, so real-call tenants do not briefly see simulations. |
| Real calls access | `src/components/teamManagement/reports/useCanViewRealCalls.ts` | True when the tenant has `Features.REAL_CALLS`, or in local development. Also used by the [Manager Home](/internal/features/manager-home) quick links. |
| Global filters | `src/components/teamManagement/reports/reportsGlobalFilters.tsx` | Renders group, user, scorecard, and date filters in one row. Date is the last filter. The report type is no longer part of this row. |
| View switch | `src/components/teamManagement/reports/ReportViewSwitch.tsx`, `reportsSwitch.tsx` | Switches between Coaching Insights and List view. The choice is stored as `activeTab` in the per-type filter state (localStorage keys `real-calls-reports-filters` and `reports-filters`) and defaults to Coaching Insights. |
| View deep link | `src/components/teamManagement/reports/useReportViewParam.ts` | `?view=coaching-insights` or `?view=reports` (List view) sets the view tab once, then the param is removed from the URL with `router.replace` so the stored tab stays the source of truth. Other values are ignored. Used by `appRoutes.toAdminTeamReportsViewPage(view, type?)`, for example from the Manager Home quick links. |
| Legacy route | `src/app/(auth)/admin/team/real-calls-reports/page.tsx` | Redirects to `/admin/team/reports?type=real-calls`. |

The Real Calls Report list uses `GET /real-calls-reports`. It receives the unified global filter state and maps scorecard filters to `scorecardIds`, user filters to `userIds`, group filters to `groupIds`, and the selected date range to `dateFrom` and `dateTo`.

The Real Calls Report Coaching Insights view uses the shared Coaching Insights tab with `source=REAL_CALL`. Its summary cards are average performance, average coaching need, and average engagement. Lower average coaching need means less remaining coaching need.
