## Overview

Real Calls Reports provide manager/admin reporting over real call performance inside the unified team Reports workspace. The feature combines call filters, evaluation data, users, groups, workspaces, and scorecards to support performance analysis.

The canonical explicit route is `/admin/team/reports?type=real-calls`. The legacy `/admin/team/real-calls-reports` route redirects to the unified Reports page with the real-calls report type selected. Without a `type` query parameter, the workspace falls back to the persisted report type in localStorage key `reports-report-type`, then to Simulation Reports.

When the real-calls reporting feature is disabled for a tenant, the report-type dropdown only exposes Simulation Reports and attempts to select real calls fall back to simulations.

## Call Detail Drilldown

Rows that open Call Analysis use the real-call header behavior documented in `internal/features/call-analysis.mdx`.

Managers and team leads can correct language, call type, and outcome from the call detail header. Admins can also edit the call title and reassign the call owner. Regular users see those metadata values as read-only.

Successful metadata and assignment saves do not show confirmation toasts; failed saves show destructive error toasts and restore optimistic metadata selections where applicable.

- `src/app/(auth)/call-analysis/[callId]/page.tsx`
- `src/components/analysis/header/useCallAnalysisHeaderActions.ts`

## Unified Reports Workspace

| UI area | Frontend source | Behavior |
| --- | --- | --- |
| Report type | `src/components/teamManagement/reports/reportTypeSelect.tsx` and `src/components/teamManagement/reports/useReportsWorkspaceModels.ts` | Selects Simulation Reports or Real Calls Report. `type=real-calls` selects real calls explicitly; otherwise the UI uses localStorage key `reports-report-type` and defaults to simulations. Changing to Real Calls Report stores `real-calls` and sets `type=real-calls`; changing to Simulation Reports stores `simulations` and removes `type`. Empty, missing, or unrecognized stored values normalize to simulations. |
| Global filters | `src/components/teamManagement/reports/reportsGlobalFilters.tsx` | Renders report type, group, user, scorecard, and date filters in one row. Date is the last filter. |
| View switch | `src/components/teamManagement/reports/reportsSwitch.tsx` | Switches between Coaching Insights and List view. The value is stored in the `view` search parameter. |
| Route guard | `src/components/teamManagement/reports/useReportsWorkspaceModels.ts` | Hides Real Calls Report when the feature flag is inactive and normalizes invalid report/view search parameters. |
| Legacy route | `src/app/(auth)/admin/team/real-calls-reports/page.tsx` | Redirects to `/admin/team/reports?type=real-calls`. |

The Real Calls Report list uses `GET /real-calls-reports`. It receives the unified global filter state and maps scorecard filters to `scorecardIds`, user filters to `userIds`, group filters to `groupIds`, and the selected date range to `dateFrom` and `dateTo`.

### List state when returning from a call

Opening a call from the list and coming back keeps the list as the manager left it. Everything is stored in the browser's localStorage, so it is per browser and not shared between users or devices.

| State | Where it is stored | Behavior |
| --- | --- | --- |
| Filters and search | `real-calls-reports-filters` (`FilterGroup` in `ReportsWorkspace.tsx`, model in `useRealCallsReportsModel.ts`) | Users, groups, scorecards, call types, outcomes, coaching score, and the search text are kept. The search text is saved after the usual search debounce. Cleared when switching tenant. |
| Date range | `real-calls-reports-date-range` (`useDateRangeWithStorage`) | Presets are recalculated from today; custom ranges are kept as chosen. The list waits for the stored range before loading, so it does not first load the default last 7 days. |
| Column sort | `tableSorting`, keyed by table id `real-calls-reports` (`src/components/react-table/tableContext.tsx`) | Kept for 1 hour. Sorting is applied in the browser to the rows of the current page only; the endpoint has no sort parameter. |
| Page and page size | `tablePagination`, keyed by table id | Kept for 1 hour. The page resets to the first page only when the list filters differ from the ones the page belonged to (`tableFixedFiltersSignature`). |

The sort, page, and filter-signature behavior lives in the shared `TableProvider` and `TableWithApiCall`, so every table built on them behaves the same way.

The Real Calls Report Coaching Insights view uses the shared Coaching Insights tab with `source=REAL_CALL`. Its summary cards are average performance, average coaching need, and average engagement. Lower average coaching need means less remaining coaching need.
